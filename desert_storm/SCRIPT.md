# Voiceover script (Hinglish)

Record this after the hook clip (the hook already has the host's question and Virat's answer, so you start right after it).

**How to record**
- One take, phone voice memo is fine. Quiet room, phone 15–20 cm from your mouth.
- Read the lines **in order** with a short breath (about half a second) between lines. That pause is how the edit finds each line, so don't run two lines together.
- Energy up, pace brisk, like telling a friend a story. Hit the **bold** words; that's where the cards and highlights land.
- Small changes in wording are fine; don't skip or reorder lines.
- Send the file as is (m4a / mp3 / wav). No need to trim or clean it.
